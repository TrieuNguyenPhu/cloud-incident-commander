# Cloud Incident Commander — Implementation Backlog v1.1

- **Ngày chốt:** 2026-10-15
- **Delivery approach:** vertical slices (mỗi phase kết thúc với 1 demo tự chạy)
- **Planning unit:** 1 story point là ước tính độ phức tạp tương đối, **không phải** số giờ.
- **MVP = P0..P4**, Full scope = P0..P7.
- **Các thời lượng** là dự toán lập kế hoạch nếu có thời gian làm việc tập trung; không phải cam kết tiến độ. Làm cá nhân bán thời gian có thể dài hơn đáng kể.

## 2. Global Definition of Done

- Story commits include typed implementation, tests, IAM/terraform plan reviews, security checks, docs and evidence URLs/IDs; green PR checks and peer review.
- AWS environment changes require explicit manual approval of Terraform plan, budgets, tag/TTL and destroy scope; CI MUST NOT auto-apply P6/P7 labs.
- Phase gate is met only with measured AWS evidence (resource identifiers redacted in published portfolio), not screenshots of mock responses.
- Acceptance criteria have trace IDs in `08_REQUIREMENT_TRACEABILITY.md` and UAT steps in `12_UAT_TEST_CASES.md`.
- Failed approval or external drift never causes mutation; all executor actions must be auditable and idempotent under re-delivery.

P0-05 + P0-03 → P1-03 → P1-09 → P1-06; P1-04 + P1-05 → P1-10 → P1-07; P1-05 → P1-12 → P1-08 → P2-01 → P2-02 → P2-03 → P2-05 → P2-06 → P3-01 → P3-03 → P3-04 → P4-01 → P4-02 → P4-04 → P4-05 → P4-06 → P4-09.

Audit critical path P1-03 → P1-11 → P4-03 → P4-07. P6-04 security precedes P6-03 live connector and P6-05 Jenkins X. P7-13..16 are real provider adapters, not placeholders.

## 4. Resource and budget gates

- MVP P0..P4 is deployable with no EKS/OpenShift/ELK/Jenkins always running.
- P6/P7 create separate Terraform states. Confirm precise resource pricing/quotas/support before apply, manually record approval and prove teardown; AWS Budgets = alerts, not spend cap.
- P7 OpenShift/ROSA story remains BLOCKED, not DONE, when prerequisites/budget/entitlement prevent provisioning. Never mark mocked OpenShift connector equivalent to real cluster.
